# YA-001 · CCM — Claude Code בענן, מהטלפון, לסרטוני מושן בעברית

A no-voiceover Hebrew motion-graphics video about using **Claude Opus 5.5 through Claude Code, even from a phone, in a cloud environment** to make Hebrew motion-graphics videos.
It was produced the same way it describes: a Claude Code cloud session running Opus 5.5 built the page, rendered it, checked its own stills and re-rendered.
The exact production prompt is in [`PROMPT.md`](PROMPT.md).

## Design system as applied

- **Arc and layers:** fog (1–2) → cloud tops with pink light (3–5) → low open sky (6–8) → high deep blue with a growing contrail (9–13) → stratosphere with stars and the Earth's limb (14–16) → golden sunrise over a sea of clouds (17). All skies are built from gradients, procedural cloud sprites (seeded canvas), stars and light; there are no photos.
- **Colors:** only the 11 brand tokens, as CSS variables in `src/index.html`. Gold is used for one marker per section (shots 2 "ימים", 4 "Claude Code", 10 "שוב ושוב", 16 "בטלפון"), the horizon (Earth-limb arc and sunrise line), and exactly one detail per icon.
- **Type:** Assistant 800/300/600 for Hebrew; Anton + Oswald 200 for the wordmark; IBM Plex Mono 600 for chips, instruments and code. All fonts are self-hosted woff2 files from @fontsource. QA asks Chromium (`CSS.getPlatformFontsForNode`) which fonts actually painted each node, and found no fallback fonts and no italics.
- **Cards:** every headline, NOTAM and visual sits on a white cloud card (36 px radius, 6 px wing-tip corner bottom-left, 2.5 px deep-sky stroke, brand shadow), so contrast holds on the dark layers too.
- **Devices:** a top flight-data strip (boarding strip, WPT n/N, live altimeter 0 → 35,000 FT); a bottom rule with timecode and wordmark; a dashed route with pins and a travelling plane; a phone ↔ control-tower link that pulses once per bar (16:9); NOTAM tags with a sunrise-pink left edge that draws in; 4 cycled grain PNGs; and a vignette.
- **Logo:** the original YUV.AI phoenix from [yuv.ai/logo.png](https://yuv.ai/logo.png), never recolored, shown only on the opening and the end card.
- **Bidi:** Hebrew lines are split into isolated word units. Latin runs are wrapped in `<bdi dir="ltr">`, consecutive Latin words are merged into one unit ("Claude Code", "Opus 5.5"), and comma-separated lists stay as separate units, so "HTML, GSAP, Playwright ו-ffmpeg" reads right-to-left with the ו prefix on the correct side. The arrow ← is an inline SVG, because Assistant has no U+2190.

## Pipeline

```
src/shots.json ─► src/timing.js (formula + beat quantize, shared by page and tools)
               ─► src/index.html + main.js (GSAP paused timeline, window.seek(t, frame), CUES/CUTS)
src/qa.mjs      ─► one still per shot + checks (fonts, overflow, 9:16 safe zone, overlaps, ≥44 px, italics)
src/contact.py  ─► contact sheets + the 3 thumbnails and end-card still the page reuses
src/render.mjs  ─► Playwright Chromium, N workers = CPU cores, CDP PNG capture → ffmpeg chunks → concat
src/audio.py    ─► procedural 108 BPM score (pad, plucks, bass, kick/snare/hats) + SFX from page CUES
src/finalize.py ─► compressor + limiter + 2-pass loudnorm → libx264 slow 5 Mbps + AAC 192k → 720p preview → ffprobe/ebur128 checks
src/evidence.mjs ─► copies the real render loop (between // <evidence> markers) into shot 9
```

Rebuild: `cd src && npm i && pip install numpy scipy pillow && ./build.sh` (`FORMATS=A ./build.sh` for one format).
The PROOF shot needs two passes: the first final render writes `src/gen/stats.json` (`finalize.py A --stats`), and the next render shows it.

## Deviations from the prompt (and why)

- **Music:** the ElevenLabs connector in this session has no credits/subscription endpoint, so credits couldn't be checked. I used the procedural numpy/scipy fallback the prompt allows. It's deterministic, exactly 108 BPM, the same length as the video to the frame, and ends on a hit at the last downbeat.
- **Shot 6 chip:** "network access · setup script" instead of "network policy · setup script", to match the setting names in the docs.
- **Extra chips, all real:** "GitHub App" (shot 5), "git push" (11), "network access: Trusted" (12), "DRAFT PR" and "MP4 · 30 fps" (14).
- **9:16 chrome:** the boarding strip appears only in the opening shot, not in the top strip, because the 44 px minimum doesn't fit three items in 860 px.
- **End card:** the bottom chrome fades out, because white text on the sea of clouds would be unreadable. The wordmark is on the card itself.
- **9:16 duration:** the beat math gives 57.222 s; whole frames give 1717 frames = 57.233 s, which is what's delivered (the 16:9 cut is exactly 2150 frames = 71.667 s).
- **Render loop:** it uses CDP `Page.captureScreenshot` (fast PNG, still lossless) instead of `page.screenshot`. That made rendering about 4× faster, and shot 9 shows this real loop.
